# James Dimachkie · Applied AI

Applied AI practitioner from finance, operations and audit. I frame practical problems, direct multi-agent builds and
test them against bars set in advance.

**[Guardcell](https://github.com/JamesDimachkie/guardcell-outlook)**: an open-source Outlook add-in that checks outgoing
email on the sender’s device and asks before a possible sensitive disclosure leaves. All nine pre-registered gate plans
are published, failures included. [Case study](https://jamesdimachkie.com/work/guardcell/)

**[Legible Film](https://github.com/JamesDimachkie/legible-film)**: an open-source Agent Skill that teaches coding agents
to make short videos the way a careful director, editor and finisher would. In a published five-request test of
version 1.0 on one model, graded by another model family, agents using it met 35 of 35 of the method’s expectations,
against 10 of 35 without.

**[Receiver Reliance](https://github.com/JamesDimachkie/receiver-reliance)**: the reference implementation for a study of
1,805 synthetic agent episodes on when one AI agent should trust another’s work,
[published on Zenodo](https://doi.org/10.5281/zenodo.22492561). In seeded-defect tests a structural check cut improper
handoffs but finished only about half the seeded tasks; a follow-up found no added benefit over an equally informed
conventional policy in the release decisions it tested, and I published that too.
[Case study](https://jamesdimachkie.com/work/receiver-reliance/)

I set the direction and the bars; teams of AI agents do much of the design, implementation, analysis and writing.
